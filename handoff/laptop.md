## 背景（第 4 回合之後，開發機改的；開發機的範圍，不要改回去）

- **機魂是預設角色**：內建人設 Machina-Prime-09A（暱稱「機魂、馬基納」），一開啟就是角色模式；AI 誠實度預設「機器角色」。
- **怎麼叫它**（使用者 2026-10-05 定的）：語音裡每一句都要喊「機魂」才回（照發音比對，「雞魂」也算），沒有時間窗；文字頻道提到「機魂」、@ 它或回覆它的訊息，就在那個頻道聊天（任何人都行）；**主人**在文字頻道 @ 它（不是回覆）會開討論串＝主人的 Agent 串，串裡主人的每一句原封不動交給 Agent，別人的話不交。用說的永遠不能動電腦。任何人都能叫它查公開資料：角色判斷要查，Agent 只拿網路工具查（EdgeAgent `scope: public`），結果打在那個聊天室，語音頻道另外用說的報重點。
- **Agent 串**：只讀的工作用唯讀跑（改動直接擋、不問）；要改的話每次私訊主人批准；結果貼在串裡（開頭「【思考機回報】」）；SilentTalk 重開後串的下一句會先把串讀回來。
- **模型與記憶體**（使用者：「我犧牲速度，cpu gpu 一起用，鎖死不溢出到ssd，然後常駐吃記憶體的非必要占用全部根除」「角色慢一點沒關係，照做」）：EdgeAgent 預設模型改成 E4B、context 128K；角色和 Agent 共用一塊 context（Agent 拿「總量 − 角色的份」）；顯示卡放不下的層自動放 CPU（`--fit`）；模型鎖在記憶體（`--load-mode mlock`）；暫存的提示每種模式都限 256 MiB。開發機 3090 量的：E4B 128K 全放 GPU 4.46–4.62 GB，36 層 4.22 GB＋鎖 2.24 GB RAM，30 層 3.63 GB＋2.55 GB。安裝程式不再有 `-CharacterAssets`（E4B 一律會裝）。
- SilentTalk 設定頁的「GPU 層數」「省 VRAM 模式」「在頻道公開 Agent 的結果」三格已經沒有作用（B1）。
